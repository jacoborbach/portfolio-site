Proof

Shipped work

GhostChat — real-time SaaS on the edge

A privacy-first chat widget with a ~15KB embeddable SDK, up to 20× smaller and 3–8× faster than legacy tools like Intercom or Drift. Built on Cloudflare Workers with Durable Objects for per-conversation state, Supabase for persistence, and Stripe for billing. The chat widget on this page is that product, running live.

Gmailytics — OAuth at scale, security-audited

A web app plus Chrome extension that scans a Gmail inbox and bulk-unsubscribes from unwanted senders. It has cleaned 5.2M+ emails and freed over 300GB of storage. It's Google CASA Tier 2 certified, meaning it passed an independent third-party security assessment for its use of restricted Gmail scopes — a bar most side projects never clear.

Salesforce migration — 100K+ records, zero downtime

At Hertz Furniture I migrated a CRM of over 100,000 records to Salesforce with zero data loss and zero downtime, then built LiveChat bots and Salesforce webhooks that cut response time from hours to under ten minutes. I also integrated Microsoft OneDrive via the Graph API, reducing storage costs by 40%.

Firebase to PostgreSQL, plus real-time

At Elphi I migrated a production application from Firebase to PostgreSQL for performance and analytical stability, and added GraphQL subscriptions so the UI updated in real time.

A theme runs through all of this: the interesting problems are rarely "build a form." They're "make these four systems agree with each other, forever, without a human checking." That's the work I like most and do best.
