Shipped work

30+ custom Gutenberg blocks and a generator to make more

At One Digital I built more than thirty custom React-based Gutenberg blocks for enterprise clients including Dimri, Sonol, and Rishumit. Building them one at a time was the bottleneck, so I wrote an automated ACF block generator — a metadata-driven scaffolder that produces the block registration, fields, and template from a definition. It cut block development time by roughly 80%.

That's the pattern I bring to WordPress work generally: if a task is going to happen fifty times, the second one should be generated, not typed.

WPML multilingual with RTL and LTR

Enterprise multilingual architecture where Hebrew and English versions share components. Right-to-left support is one of those requirements that sounds like a CSS flag and turns out to touch layout, iconography, form flow, and every third-party embed on the page.

KaspaWoo — an open-source WooCommerce payment gateway

A production cryptocurrency payment gateway for WooCommerce, open-sourced on GitHub and powered by kaspa-simple-wallet, an MIT-licensed npm package I wrote for watch-only address derivation. Merchants receive payments directly to their own wallet — no custody, no middleman.

PDF generation at scale

Dockerized Puppeteer running on Azure Functions to generate invoice PDFs automatically — the kind of integration that sits behind WordPress and Strapi rather than inside it, and the reason it helps to hire someone who does both.
